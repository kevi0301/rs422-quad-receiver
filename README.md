# RS-422 Quad Receiver PCB
![RS-422 Receiver PCB 3D View](rs-422_3d_screenshot.png)
4-channel RS-422 receiver PCB designed in KiCad with AC termination, TVS protection, test points, and fabrication outputs. 
## Features
- 4-channel RS-422 differential receiver
- AM26C32 receiver IC
- SM712 TVS protection for each input channel
- Configurable enable control with pull-up and pull-down resistors
- Power indicator with LED and 5V power input
- Local 0.1 uF decoupling capacitor
- Test points included in 5V, GND, and Y1-Y4 outputs
- 2-layer PCB with ground copper plane
- Mounting holes with copper keep-out areas
## PCB Design
- Designed and routed in KiCad
- Top and bottom copper routing
- Ground plane implemented on B.Cu
- DRC completed with 0 violations and 0 unrouted connections
- Silkscreen labeling added for debugging and board identification
## Fabrication
Gerber and Excellon PTH/NPTH drill files are included in the Fabrication folder.
